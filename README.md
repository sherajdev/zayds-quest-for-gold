# Zayd’s Quest for Gold

A self-contained browser adventure game built with HTML, CSS and JavaScript. No build step, server, external assets or dependencies.

## Deploy to GitHub Pages

1. Create a public GitHub repository named `zayds-quest-for-gold`.
2. Extract this ZIP and upload its contents to the root of the repository (not inside another folder). Commit to `main`.
3. Go to Settings → Pages. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Once published, open `https://YOUR-USERNAME.github.io/zayds-quest-for-gold/` (replace YOUR-USERNAME).

## Play locally

Open index.html in a desktop browser.

## Controls

| Key | Action |
|---|---|
| W A S D | Move |
| 1 | Switch between Zayd and Aahil before betrayal |
| Space | Attack |
| Q | First special skill |
| F | Second special skill |
| Z | Ultimate / Z Finisher |
| R | Sprint |
| E | Interact |
| M | Map |

| Key | Zayd | Aahil |
|---|---|---|
| Space | Sword strike | Golden arrow |
| Q | Cyclone Slash | Triple Golden Arrow |
| F | Guardian Shield | Shadow Dash |
| Z | Z Lightning / Finisher | Golden Barrage |

Explore four regions, defeat guardians, collect treasure maps, and confront Aahil in the final chapter. Use Z when his health is low to finish the battle.

Progress is held in memory during the current session; reloading starts a new adventure.
